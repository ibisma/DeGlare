DeGlare

Self-Supervised Specular Removal for Industrial Metallic Surfaces via Multi-Illumination Priors

View on GitHub

The Multi-Illumination industrial Rig (MIR) Dataset

Download MIR dataset v1.0

Or, from a clone of the repository:

bash scripts/download_dataset.sh

Directory layout (images are numbered 0001.jpg, 0002.jpg, … within each folder):

dataset/
├── training/
│   └── train-val-split/
│       ├── train/     # 384 input images
│       └── val/       # 97 input images
├── test/
│   ├── test1/         # 150 input images
│   └── test2/         # 150 input images
└── gt/
    ├── training/      # weiss_train.png: approximate diffuse label (Weiss estimate) used for training
    ├── test1/
    │   ├── gt_test1.png        # ground-truth diffuse reference
    │   └── mask/
    │       ├── mask_img.png    # mask as image
    │       └── mask_numpy.npy  # mask as NumPy array
    └── test2/
        ├── gt_test2.png
        └── mask/
            ├── mask_img.png
            └── mask_numpy.npy
